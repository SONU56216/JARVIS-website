# 🌌 About The Project

<img align="right" width="320" src="https://media.giphy.com/media/l0HlNaQ6gWfllcjDO/giphy.gif">

JARVIS AI Website is a futuristic and animated web experience inspired by advanced AI systems like Iron Man JARVIS.

This project combines:

* 🤖 Artificial Intelligence aesthetics
* ⚡ Smooth animations
* 🌐 Modern web technologies
* 💎 Glassmorphism UI
* 🚀 Cyberpunk design

The website was designed to feel cinematic, immersive, and futuristic.
